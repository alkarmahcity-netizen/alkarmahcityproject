# لوحة متابعة مشاريع قضاء الكرمة

موقع ثابت (Static Site) يعرض بيانات لجنة متابعة مشاريع قضاء الكرمة (47 مشروعاً)، مبني من ملف `لوحة_مشاريع_الكرمة.xlsx`.

## الملفات
- `index.html` — الصفحة الكاملة (التصميم + المنطق)
- `data.js` — بيانات المشاريع الـ47 (مستخرجة من ملف الإكسل)

## طريقة النشر على GitHub Pages (بدون أي خبرة برمجية)

1. أنشئ حساباً على github.com إذا لم يكن لديك واحد.
2. اضغط زر **New repository** (مستودع جديد). اختر اسماً مثل `karma-projects`، واجعله **Public**، ثم اضغط **Create repository**.
3. داخل المستودع، اضغط **uploading an existing file** (أو Add file → Upload files).
4. اسحب الملفين `index.html` و `data.js` وارفعهما، ثم اضغط **Commit changes**.
5. اذهب إلى تبويب **Settings** أعلى المستودع → من القائمة الجانبية اختر **Pages**.
6. تحت **Build and deployment** اختر Source: **Deploy from a branch**، والفرع (Branch): **main**، والمجلد: **/ (root)**، ثم **Save**.
7. انتظر دقيقة أو دقيقتين، ثم سيظهر رابط الموقع أعلى الصفحة بالشكل:
   `https://<username>.github.io/karma-projects/`

هذا الرابط هو الموقع الجاهز للمشاركة مع اللجنة أو نائب المحافظ — يعمل من أي هاتف أو حاسوب.

## عند تحديث بيانات المشاريع لاحقاً
عندما يتحدّث ملف الإكسل، يكفي إرسال الملف الجديد ليُعاد استخراج `data.js` منه، ثم رفع الملف المحدَّث فقط عبر نفس خطوة "Upload files" في GitHub — لا حاجة لإعادة بناء الموقع بالكامل.
