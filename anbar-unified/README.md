# نظام الشؤون الهندسية الموحد — قسم الشؤون الهندسية / محافظة الأنبار

برنامج Windows (Electron 22.3.27) يجمع: أوامر التغيير، المدد والتوقف، لجنة تدقيق السلف، إطلاق التأمينات، الاستلام، المخاطبات، الموقف العام، مشاريع التخطيط، سير المعاملات.

استُرجع الكود في 19/11/2026 من ملف البرنامج المنشور 1.64.0 بعد فقدان مجلد العمل الأصلي. لا تشمل هذه النسخة الاختبارات الآلية القديمة ولا مصادر الأنظمة المقسّمة
(صفحات الأنظمة مبنيّة في `unified/app/*.html` وتُعدَّل هناك).

## البناء
```
cd unified && npm install && npm run build:win    # dist/AnbarEngineering-<ver>-Windows-x64.exe
```

## 1.65.0 — مشاريع التخطيط: ملف التخصيصات + حيّ مع الموقف العام
- «📥 استيراد ملف التخطيط» يقرأ **ملف التخصيصات** (ورقة Projects)، وتُترك AnnualAllocation وأوراق السنوات السابقة. حقول إضافية: المدد الإضافية، الكلفة الكلية (مبلغ العقد)،
  الكلفة المصادقة، المصروف التراكمي، نسبة الإنجاز المالي، التخصيص الكلي 2026. ملف الخطة العام يُقرأ كما كان تماماً.
- **حيّ مع الموقف العام:** المكوّن المرتبط باضبارة تُعرض قيمه من الموقف بعلامة «↻ من الموقف» وتتحدث الصفحة تلقائياً عند تغيّر الموقف؛
  ملف التخطيط المحفوظ لا يتغير إلا عند «⬇ تصدير ملف التخطيط المحدَّث».
- اختبار: `UNI_TEST_ALLOC_FILE=<ملف التخصيصات> xvfb-run -a node test-planalloc.js`
- البناء على لينكس دون wine (`win.signAndEditExecutable=false`): الملف الداخلي يظهر باسم Electron في مدير المهام، ولا يؤثر على العمل.

## 1.66.0 — تاريخ الإنجاز الفعلي في الموقف العام
- عمود «تاريخ الإنجاز الفعلي» (أو «تاريخ الانجاز الحقيقي / تاريخ اكمال العمل») في ملف موقف أي لجنة يُقرأ ويظهر في بطاقة المشروع «(من ملف الموقف)».
- المشروع **المنجز** بلا تاريخ: تذكير «⏳ لم يُدخل تاريخ الإنجاز الفعلي» وحقل تاريخ + «💾 حفظ» في «الكلفة والمدة» (يُحفظ مع بيانات المشروع ويُزامن بين الحاسبات؛ لا يُقبل تاريخ بعد اليوم).
- يُعرض d/m/y مع التأخر عن المخطط أو التقدّم عليه، ويُضاف عموداً في آخر تصدير Excel وCSV، ويُملأ في نموذج اللجنة إن كان فيه العمود.
- اختبار: `xvfb-run -a node test-actualend.js`

## 1.67.0 — الكلفة المصادقة
- ملف التخطيط: عمود «الكلفة المصادقة» يُقرأ حقلاً مستقلاً (approved) للمكوّن والمشروع التخطيطي (لا يخلط بالكلفة التخمينية)، ويظهر في بطاقة المكوّن وشجرة المشاريع.
- الموقف العام: «الكلفة المصادقة» في «الكلفة والمدة» ببطاقة المشروع — من عمود «الكلفة المصادقة» في ملف موقف اللجنة إن وُجد، وإلا من ملف التخطيط للمكوّن المرتبط (مع ذكر المصدر)؛
  وعمود في آخر تصدير Excel وCSV، ويُملأ في نموذج اللجنة. «⬇ تصدير ملف التخطيط المحدَّث» يكتب الكلفة المصادقة من الموقف في عمودها (إن وُجدت في الموقف).

## 1.68.0 — «✔ تحققتُ — تجاهل هذا الفرق»
- بجانب كل خلل في بطاقة المشروع (الموقف العام): زر «✔ تحققتُ — تجاهل هذا الفرق» (بتأكيد). يُخفى الفرق لهذا المشروع ولا يُعدّ خللاً في الجدول والتقارير،
  ويظهر في «✔ فروقات تحققتَ منها» مع «إلغاء». يُحفظ مع بيانات المشروع ويُزامن، ويعود تلقائياً إن تغيّر أي رقم في الفرق (البصمة من نصه بأرقامه).
- اختبار: `xvfb-run -a node test-ackiss.js`

## 1.69.0 — «تاريخ استلام الذمة» في نظام المدد
- شريط «📋 لوحة سير المعاملات» داخل نظام المدد: النظام يحوّل حقل التاريخ إلى «يوم/شهر/سنة» + زر تقويم ويُرسل input لا change، فكان التاريخ لا يُحفظ
  ولا يظهر المحفوظ. الآن يُستمع للحدثين (دون إرسال التاريخ نفسه مرتين)، ويُحدَّث الحقل المرئي بالتاريخ المحفوظ، ويُعطَّل الحقل المرئي وزر التقويم للملف بلا توقف ولا مدة.
- اختبار: `UNI_TEST_DU_PW=<كلمة سر المدد> xvfb-run -a node test-wfdate.js` (كلمة السر من البيئة فقط).
