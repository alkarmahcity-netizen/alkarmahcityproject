# نظام الشؤون الهندسية الموحد — قسم الشؤون الهندسية / محافظة الأنبار

برنامج Windows (Electron 22.3.27) يجمع: أوامر التغيير، المدد والتوقف، لجنة تدقيق السلف، إطلاق التأمينات، الاستلام، المخاطبات، الموقف العام، مشاريع التخطيط، سير المعاملات.

استُرجع الكود في 19/11/2026 من ملف البرنامج المنشور 1.64.0 بعد فقدان مجلد العمل الأصلي. لا تشمل هذه النسخة الاختبارات الآلية القديمة ولا مصادر الأنظمة المقسّمة
(صفحات الأنظمة مبنيّة في `unified/app/*.html` وتُعدَّل هناك).

## البناء
```
cd unified && npm install && npm run build:win    # dist/AnbarEngineering-<ver>-Windows-x64.exe
```

## 1.65.0 — مشاريع التخطيط: ملف التخصيصات + حيّ مع الموقف العام
- «📥 استيراد ملف التخطيط» يقرأ **ملف التخصيصات** (ورقة Projects)، وتُترك AnnualAllocation وأوراق السنوات السابقة. حقول إضافية: المدد الإضافية، الكلفة الكلية (مبلغ العقد)،
  الكلفة المصادقة، المصروف التراكمي، نسبة الإنجاز المالي، التخصيص الكلي 2026. ملف الخطة العام يُقرأ كما كان تماماً.
- **حيّ مع الموقف العام:** المكوّن المرتبط باضبارة تُعرض قيمه من الموقف بعلامة «↻ من الموقف» وتتحدث الصفحة تلقائياً عند تغيّر الموقف؛
  ملف التخطيط المحفوظ لا يتغير إلا عند «⬇ تصدير ملف التخطيط المحدَّث».
- اختبار: `UNI_TEST_ALLOC_FILE=<ملف التخصيصات> xvfb-run -a node test-planalloc.js`
- البناء على لينكس دون wine (`win.signAndEditExecutable=false`): الملف الداخلي يظهر باسم Electron في مدير المهام، ولا يؤثر على العمل.
