# مشاريع التنفيذ أمانة — برنامج مستقل

برنامج Windows مستقل (Electron 22.3.27) لشعبة تنفيذ العمل أمانة — قسم الشؤون الهندسية / محافظة الأنبار.
نافذة واحدة بتبويبين: **📁 المشاريع** (لوحة المعلومات، المشاريع، المهندسون واللجان، السلف، تدقيق السلف، الخريطة، الإعدادات) و**✉️ المخاطبات** (المطالعة والأمر الإداري بترويسة الشعبة).

- صفحة المشاريع `am.html` في هذا المجلد؛ ومن البرنامج الموحد (`../unified/app/lt.html` بوضع `aml`، `../unified/shell/xlwriter.js`، `../unified/shell/anbar-geo.js`)؛ `prepare.js` ينسخها الى `app/` و`shell/` قبل التشغيل والبناء.
- البيانات: مجلد «بيانات مشاريع الأمانة» بجانب ملف البرنامج (يُنقل معه)، وإن تعذّرت الكتابة هناك ففي «المستندات». الملفات: `AmanaProjects-Data.json`، `AmanaLetters-Data.json`، `prefs.json`،
  ونسخة احتياطية يومية لكل ملف (آخر 30) في «نسخ-احتياطية». الحفظ المؤجل يُكتب قبل إغلاق النافذة.
- ملفات البيانات بالصيغة نفسها التي يستعملها النظام داخل البرنامج الموحد، فيمكن نقلها بينهما.

## البناء
```
cd amana && npm install && npm run build:win    # dist/AmanaProjects-<ver>-Windows-x64.exe
```
## الاختبار
`xvfb-run -a node test-amana.js` (التبويبان، الحفظ في مجلد البيانات وعند الإغلاق، إعادة الفتح، الأمر الإداري في المخاطبات بترويسة الشعبة، النسخة الاحتياطية).

## 1.1.0
- **Excel ذهاباً وإياباً:** «📤 الموقف بالإكسل» يضيف عمود «المعرّف» (ورقة الموقف) و«معرّف المشروع/السلفة» (ورقة السلف). تعدّل في Excel الإحداثيات (أو تلصق رابط خرائط Google في «رابط الموقع»)
  ونسبة الإنجاز والحالة والمبالغ والأسماء، وتضيف سطوراً لمشاريع أو سلف جديدة، ثم «📥 استيراد Excel» بالملف نفسه فيتحدث البرنامج. الخلية الفارغة لا تمسح قيمة؛ مبالغ السلف تُعدَّل في ورقة «السلف».
- **المخاطبات — «+ أمر إداري»** بنماذج الشعبة: تشكيل لجنتي تنفيذ وتسلم العمل أمانة (مع إلغاء أمر سابق واعتماد الكشف اختيارياً)، تعديل لجنة (إعفاء وبديل)، إلغاء أمر، صرف مبلغ (سلفة).
  يُختار المشروع من بيانات البرنامج فيُملأ الاسم والقضاء والمبلغ كتابةً وجدولا اللجنتين، والتوقيع لمحافظ الأنبار من إعدادات المخاطبات.
- **تدقيق السلف — استمارة «قرار لجنة تدقيق السلف»** بتصميم استمارة السلف في برنامج القسم الهندسي نفسه (الشارات، اللوحات الثلاث، شريط النسب، السلف السابقة، القرار والمبلغ كتابةً، التواقيع والمصادقات)
  ببيانات التنفيذ أمانة، وصفحة ثانية «كشف الوصولات والفحوصات المدققة». معاينة ثم طباعة أو PDF.

## 1.2.0 — «🏁 شهادة الإنجاز»
- شهادة إنجاز العمل للتنفيذ أمانة بتصميم «محضر وشهادة الاستلام الأولي» في نظام الاستلام بالبرنامج الهندسي (جداول زرقاء، ثلاث صفحات A4: البيانات وتواقيع اللجنة، التتمة، التواقيع والمصادقات الأربع).
- تصدرها لجنة التسلم (م2/رابعاً): البيانات من المشروع (الأمر الإداري، اللجنتان، الجهة المستفيدة، الموقع والإحداثيات، المبلغ، السلف، المعزَّز من تدقيق السلف وما بذمة لجنة التنفيذ، المباشرة والإنجاز)،
  ونصوص مقترحة (الفحوصات من تدقيق السلف، التسليم للجهة المستفيدة، إبراء ذمة لجنة التنفيذ من تاريخ التسلم، التوصيات، نسخة الى القسم المالي للتسوية).
- رقم محضر تلقائي AM-<السنة>-<تسلسل>؛ «صادرة» تجعل المشروع «مستلم» بتاريخ التسلم. تنبيهات: التسلم بعد 3 أشهر من الإنجاز، سلف غير مدققة، مبلغ بذمة لجنة التنفيذ، لا أسماء لجنة تسلم.
- ورقة «شهادات الإنجاز» في موقف Excel.

## 1.3.0 — الأوامر المكررة، وتواقيع شهادة الإنجاز
- **الأوامر المكررة لنفس المشروع** (إعادة تشكيل، تعديل الكشف، أو ورود الأمر في سنتين): تُكشف بعد كل استيراد وعند أول فتح بمفتاح الاسم الموحَّد، أو تشابه كلمات ≥ 85% في القضاء نفسه
  بشرط تطابق الأرقام الواردة في الاسم («حي الفارق 1» و«2» مشروعان). يبقى الأمر الأحدث رئيسياً وتُنقل إليه السلف؛ الأوامر السابقة (`dupOf`) مخفية من القائمة والمجاميع،
  والشخص يُحسب **مرة واحدة للمشروع** في عدد لجانه. «🔁 فحص التكرار» يعرض المجموعات، و«ليس مكرراً» يفصل الأمر نهائياً (`notDup`). في بياناتك: 47 أمراً مكرراً لـ44 مشروعاً.
- **شهادة الإنجاز:** حُذف «ممثل لجنة المتابعة». التوقيع من كل أعضاء لجنة التسلم (المستلِمة) وكل أعضاء لجنة تنفيذ العمل (المسلِّمة) في صفّين، والمصادقات ثلاث: الجهة المستفيدة، قسم الشؤون الهندسية، نائب المحافظ.

## 1.3.1 — مصادقات شهادة الإنجاز
- الصفحة الثالثة: مصادقة الجهة المستفيدة، مدير شعبة تنفيذ العمل أمانة، مدير قسم الشؤون الهندسية، معاون المحافظ للشؤون الفنية، نائب المحافظ للشؤون الفنية (الأسماء من نموذج الشهادة).
