# سكربت التقارير الشهرية لدوائر المهندس المقيم (Google Apps Script)

نموذج يملؤه المهندس المقيم من هاتفه كل شهر، فيصل التقرير PDF الى بريد القسم ويُحفظ في Drive، ويجلبه برنامج «نظام الشؤون الهندسية الموحد» (تبويب «تقارير دوائر المهندس المقيم الشهرية»).

## الملفات
| الملف | مكانه في مشروع Apps Script |
|---|---|
| `Code.gs` | ملف `Code.gs` |
| `index.html` | ملف HTML باسم `index` (نموذج المقيم — الإصدار 8) |
| `dashboard.html` | ملف HTML باسم `dashboard` (لوحة القسم `?page=reports`) |

`src/index.src.html` مصدر النموذج، و`src/logo.b64` شعار المحافظة. يُبنى `index.html` باستبدال `__LOGO__` في المصدر بمحتوى `logo.b64`.

## قبل النشر
في `Code.gs` (هذه النسخة العامة بلا القيم الحقيقية):
- `DEPT_EMAIL`: بريد القسم الذي يستلم التقارير.
- `DASH_CODE`: رمز لوحة القسم (يُكتب أيضاً في إعداد التبويب في البرنامج، ولا يُعطى للمقيمين).

## النشر والتحديث
1. Deploy ← New deployment ← Web app، Execute as: **Me**، Who has access: **Anyone** (أول مرة فقط).
2. لكل تحديث: الصق الملف الجديد ← حفظ ← Deploy ← **Manage deployments** ← ✏️ ← Version: **New version** ← Deploy. الرابط لا يتغير (لا تستعمل New deployment).
3. تأكد أن رأس النموذج على الهاتف يقول «نموذج الإصدار …» برقم آخر إصدار.

## ما في النموذج (الإصدار 8)
- ترويسة: جمهورية العراق / محافظة الانبار / مكتب نائب المحافظ للشؤون الفنية / د.م.م لمشروع (اسم المشروع)، والتاريخ في أقصى اليسار.
- يُحفظ التقرير كله في متصفح هاتف المقيم (عدا الشهر والتوقيع والصور) فيجده جاهزاً الشهر القادم، مع زر «مسح المحفوظ».
- صورة الختم ≤ 200 كيلوبايت، وصور الموقع (حتى 4) تُضغط داخل النموذج الى ≤ 300 كيلوبايت للصورة، وتُرسل ملفات مستقلة لبطاقة المشروع في البرنامج.
- أوامر التغيير: العدد، صافي المبالغ (يقبل السالب)، ومبلغ العقد مع الأوامر (تلقائي).
- النصوص الطويلة تُرسم بمحرك المتصفح ثم تدخل PDF (تمنع تقطّع الحروف العربية في Safari على iPhone).
